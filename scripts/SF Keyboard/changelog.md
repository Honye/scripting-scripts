# 更新日志

本文件记录 SF Keyboard 的版本变更，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## 1.0.1 — 2026-08-14

### 新增

- 调色板渲染模式支持分别配置三层颜色（之前是拿主色按透明度硬凑的）
- 渲染主题同步应用到键盘和 App 的图标网格，不再只作用于复制/导出的 PNG。
  背景选了白/黑底时格子底色也跟着变，网格就是导出效果的真实预览。
  键盘在唤起时读取一次，改完主题下次唤起生效
- 主应用的图标网格不再分页，一次铺完整个分类

### 修复

- 背景选「透明」时复制和导出的 PNG 不是透明的。底色原先用 `ZStack` 的
  `background` 修饰符，它按内容尺寸算而不是按 `frame`：选透明时那层多余的底
  吃掉了 alpha，选白/黑底时也只画出图标那么宽的一条色带。改用铺满的 `Rectangle`
- 键盘左侧分类栏滑不动、点不动。瓶颈不在分类栏本身，是右侧网格占满了主线程：
  - 分页页码改为从数据源派生，不再靠 `useEffect` 重置 —— 之前切换分类的第一帧
    仍按旧页数构造，翻过几页之后会先铺开好几百个格子再缩回一页
  - 键盘每页从 120 降到 60，长按菜单去掉二级子菜单（菜单是逐格构造的，
    节点数按页大小成倍放大）；首帧节点数从约一万降到四百
  - 分类、搜索词、待删除长度合并成一个 state，切分类从最多三次更新降为一次
  - 侧栏保持普通 `VStack`（29 个固定高度项不需要 `LazyVStack`），
    并给 `ScrollView` 补上确定的视口高度

## 1.0.0 — 2026-08-14

首个版本。

### 键盘

- 自定义键盘：左侧分类栏 + 右侧图标网格
- 点按图标把图标名输入到光标处，并计入「最近」
- 长按图标弹出菜单：输入名称 / 复制名称 / 复制 PNG（128、256、512px 三档）
- 复制 PNG 时同时写入 `public.png` 和 `public.plain-text`
  —— 粘贴到文本框得到名称，粘贴到图片位置得到图片
- 「取词搜索」：取光标前的最后一个词做筛选，选中图标时先删掉这个词再插入名称
- 「最近」分类按使用记录维护，最多 48 个
- 底部工具条：回到脚本列表 / 空格 / 删除 / 换行
- 键盘底色跟随系统，随输入框的 `keyboardAppearance` 变化

### 图标数据

- 内置 26 个官方分类、约 2450 个符号，`indices` 分类按规则生成
- 首次运行用 `UIImage.fromSFSymbol()` 逐个校验，剔除当前 iOS 版本不存在的名称，
  结果落盘到 App Group 后不再重复校验
- 支持导入源文件更新图标列表，可多选、可合并或覆盖：
  - SF Symbols.app 的 `symbol_categories.plist` / `name_availability.plist` /
    `categories.plist`（二进制和 XML plist 都能解析，不需要先转格式）
  - JSON（数组、分类 → 名称数组、`{name, categories}` 列表等）
  - CSV（`name,category`）
  - 纯文本（每行一个名称，支持 `# 分类名` 分节和 `分类: 名称`）
- 导入后自动跑一遍可用性校验并报告结果

### App

- 浏览、搜索、按分类筛选图标
- 「更多」菜单：导入并合并 / 导入并覆盖 / 重新校验 / 导出当前列表 /
  清空最近使用 / 恢复内置列表
- 图标详情对齐 SF Symbols.app 的检查器，分三个面板：
  - **信息**：名称、所属分类、同族变体（探测真实存在的 `.fill`、`.circle`
    等后缀，点按可切换预览）
  - **主题**：渲染模式、渐变、可变值、16 色取色盘、不透明度、背景
  - **动画**：动画类型、变体、重复播放、速度、播放
- 详情页底部常驻复制名称 / 复制 PNG / 导出 PNG
- 主题设置存在共享域，键盘长按复制出来的 PNG 用的是同一套样式

### 其他

- 中英双语，跟随系统语言（`Device.systemLanguageCode`）
- 浅色 / 深色配色，前景色用系统语义色自动适配
- 图标网格分页渲染（键盘每页 120 个、App 每页 200 个），
  避免一次构造上万个视图节点导致列表滑不动、按钮点不动
- 切换分类或改搜索词时列表回到顶部

### 已知限制

- 不支持复制为 SVG：Scripting 拿不到 SF Symbols 的矢量路径，只能渲染位图
- 键盘里没有输入框式搜索，键盘扩展中 TextField 抢焦点不可靠，改用「取词搜索」
- 动画的「方向」和「作用范围」合并成一个「变体」选项：SwiftUI 桥接过来的是一串
  固定的效果名，存在 `bounceUp` 和 `bounceByLayer`，但没有 `bounceUpByLayer`
